# GameplayFootball Mobile 2026/27 (Android)

Prototipo Android jugable **2D**, con interfaz original inspirada en las capturas aportadas por el usuario. No es un port 3D del GameplayFootball C++ de Linux ni incorpora sus modelos 3D.

## Cómo construir
Requiere Java 17, Android SDK 35, Gradle 8.9:
\`\`\`bash
gradle -p android :app:assembleDebug
\`\`\`
APK generada en: \`android/app/build/outputs/apk/debug/app-debug.apk\`.
También la publica la acción \`Compilar APK Android 2026\` de GitHub.

## Funciones
Inicio en español, modos de juego, selección de dos equipos ficticios, alineaciones 4-3-3 / 4-4-2 / 3-5-2, presentación de equipos, partido 2D interactivo sin conexión, marcador televisivo, goles y resultado, controles táctiles, estrategia, cámara panorámica / táctica, pausa y selector de calidad.
